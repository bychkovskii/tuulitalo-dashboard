# Чи·Тай / Пи·Ши — дашборд постинга

Недельный план публикаций для проекта **Чи·Тай / Пи·Ши** (Мультивселенная Дома Ветра Тулитало).
Собран по образцу рабочего дашборда Lifestyle × Лига Ставок.

**Живой дашборд:** https://bychkovskii.github.io/tuulitalo-dashboard/

## Что внутри

- **Сетка 3 × 7** — три слота в день (8:00 / 13:00 / 20:00 МСК) × семь дней.
- **21 ролик в неделю**, каждый выходит одновременно на 5 площадок = **105 публикаций**.
- **Клик по плитке** открывает полный бриф: сюжетка, бренд-элементы, звук, субтитры, хештеги.
- **Режим просмотра** — `?readonly=1`. Для редактора и продюсера: видят всё, ничего не ломают.
- **Блок референсов** — контент-столпы, площадки и чек-лист до запуска.

## Как править

Единственный источник правды — `weekly_plan_w40.json`. Файл `weekly_data.js` генерируется из него.

```
1. Правим weekly_plan_w40.json
2. node regen_weekly_js.js
3. Ctrl+F5 в браузере
```

Неделя: **40 (2026), 5–11 октября**.

## Почему всё в одном ролике

Один исходник идёт на пять площадок. Разводить по времени нельзя — иначе перестаёт работать
сводный охват: неделю смотришь по одной метрике, а не по пяти разным.

Фактическое время публикации задано в JSON полем `actual_time` — разброс от слота ±15 минут,
чтобы алгоритмы площадок не виделиrobot-расписание.
